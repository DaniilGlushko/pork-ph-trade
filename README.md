# Свинина Россия → Манила: первый контейнер и рост

**Открыть:** https://daniilglushko.github.io/pork-ph-trade/

Калькулятор для нас: покупаем у завода с ворот по цене российского рынка, сами везём и продаём импортёру в Маниле. Два прогноза (реальный и очень хороший), первый контейнер корпусной шкурки, рост после теста и вариант с хребтовой шкуркой и щековиной. Настройки сохраняются в ссылке.

Вся логика — в `index.html`, без сборки. Вид и стили взяты со страницы по говядине (`halal-ph-test`).
